# Лабораторная работа № 4. Каррирование и частичное применение

В `item_filtering.py` выполнены три уровня задания: ручное каррирование
фильтра словарей, частичное применение через `functools.partial` и фильтрация
чисел каррированным предикатом. Все результаты представлены списками,
как требуется в условии.

## Запуск

Из корневой папки проекта:

```powershell
python Лаба_4/item_filtering.py
```

Используется только стандартная библиотека Python. Программа выводит:

```text
Электроника: [{'name': 'Ноутбук', 'category': 'electronics', 'price': 1000}, {'name': 'Телефон', 'category': 'electronics', 'price': 800}]
Одежда: [{'name': 'Футболка', 'category': 'clothes', 'price': 50}, {'name': 'Джинсы', 'category': 'clothes', 'price': 100}]
Больше 10: [12, 20, 15]
Больше 5: [12, 20, 8, 15]
```

## 1. Импорт partial

```python
from functools import partial
```

`from` указывает модуль, `functools` — его имя, `import` подключает имя `partial`.
`partial` создаёт вызываемый объект с заранее заданными аргументами функции.
Саму функцию в момент подготовки он не выполняет.

## 2. Уровень 1: ручное каррирование filter_by

```python
filter_by = lambda key: lambda value: lambda items: [
    item for item in items if item[key] == value
]
```

Это одна инструкция присваивания функции имени `filter_by`.
Несколько строк используются для удобства чтения; внутри квадратных скобок
переносы разрешены.

Разбор по элементам:

1. `filter_by` — имя функции: «отфильтровать по».
2. `=` — присваивание.
3. `lambda` — создание анонимной функции.
4. `key` — единственный аргумент первой функции: ключ словаря.
5. `:` после `key` — отделяет параметры `lambda` от её выражения-результата.
6. `lambda value:` — результат первой функции: функция, принимающая искомое значение.
7. `lambda items:` — результат второй функции: функция, принимающая список словарей.
8. `[` и `]` — создание результирующего списка через списковое включение.
9. Первый `item` — элемент, который нужно включить в результат при выполнении условия.
10. `for item in items` — перебор элементов входного списка.
11. `if` — условие включения элемента в результат.
12. `item[key]` — получение значения словаря по ключу. Здесь скобки означают обращение
    к элементу, а не создание списка.
13. `==` — оператор сравнения на равенство.
14. `value` — значение, с которым сравнивается поле словаря.

Общая форма спискового включения:

```python
[элемент for переменная in последовательность if условие]
```

Пример по шагам:

```python
by_category = filter_by("category")
only_electronics = by_category("electronics")
result = only_electronics(items)
```

Первый вызов задаёт ключ, второй — значение, третий — список и выполняет отбор.
То же самое кратко:

```python
filter_by("category")("electronics")(items)
```

Это каррирование: функция с тремя логическими аргументами представлена цепочкой
из трёх функций, каждая из которых принимает один аргумент.
Вызов `filter_by("category", "electronics", items)` этой реализации не подходит:
внешняя функция принимает только `key`.

Внутренние функции сохраняют доступ к `key` и `value` — это замыкания.
Они позволяют заранее подготовить фильтр и применять его к разным спискам.

Использована проверка `item[key] == value` из условия задачи.
Если у словаря нет указанного ключа, возникнет `KeyError`.
В примерах у всех товаров есть поле `category`.

## 3. Уровень 2: filter_by_category через partial

```python
filter_by_category = partial(
    lambda key, value, items: filter_by(key)(value)(items), "category"
)
```

`partial` принимает функцию и аргументы, которые нужно задать заранее.
Здесь ему передаются два аргумента:

1. `lambda key, value, items: filter_by(key)(value)(items)` — функция-переходник.
   Она принимает три аргумента одним вызовом и передаёт их в каррированную
   `filter_by` тремя последовательными вызовами. Сам алгоритм отбора не дублируется.
2. `"category"` — заранее заданный первый аргумент переходника, то есть `key`.

Таким образом, новая функция ожидает только значение и список:

```python
filter_by_category("clothes", items)
```

Это эквивалентно:

```python
filter_by("category")("clothes")(items)
```

Важное различие с последним примером из задания: `partial(filter_by, "category")`
сам по себе создаёт обёртку, у которой аргумент внешней `lambda key` уже задан.
Вызов такой обёртки без аргументов вернул бы следующую функцию `lambda value`.
Если сразу передать ей `"clothes"`, внешняя `lambda` получит два аргумента
вместо одного и возникнет `TypeError`. `partial` не распределяет аргументы
автоматически по вложенным вызовам, поэтому в решении используется переходник.

## 4. Уровень 3: greater_than и filter

```python
greater_than = lambda threshold: lambda x: x > threshold
```

- `greater_than` — имя функции: «больше чем».
- `=` — присваивание.
- `lambda threshold:` — первая функция принимает порог.
- `lambda x:` — возвращённая функция принимает проверяемое число.
- `>` — оператор сравнения «строго больше».
- `x > threshold` — выражение с результатом `True` или `False`.

Например:

```python
over_ten = greater_than(10)
over_ten(12)  # True
over_ten(10)  # False
over_ten(3)   # False
```

`over_ten` — предикат, то есть функция, возвращающая логический результат.
Равное порогу число не проходит проверку, потому что используется `>`, а не `>=`.

```python
list(filter(over_ten, numbers))
```

Вызовы выполняются изнутри наружу:

1. `filter(over_ten, numbers)` создаёт ленивый итератор отбора.
2. При обходе он вызывает `over_ten` для чисел и оставляет те, для которых
   предикат возвращает истину.
3. `list(...)` обходит итератор до конца и собирает результаты в список.

Создание `filter` не выполняет весь отбор сразу; в данном коде его запускает
потребление итератора функцией `list`.

## 5. Демонстрационный блок

```python
if __name__ == "__main__":
```

`if` начинает проверку, `__name__` — специальная переменная Python,
`==` сравнивает её со строкой `"__main__"`. Блок с отступом выполняется
при прямом запуске файла и пропускается при обычном импорте.

`items = [...]` задаёт список товаров. Каждый товар — словарь в фигурных
скобках `{...}`. Двоеточие внутри словаря разделяет ключ и значение,
запятые разделяют пары и отдельные товары. Поле `price` показывает, что
в словаре могут быть дополнительные данные: фильтрация их сохраняет.

```python
numbers = [1, 5, 12, 3, 20, 8, 15, 2]
```

Это исходный список чисел. Порядок прошедших отбор элементов сохраняется.

```python
filter_clothes = partial(filter_by_category, "clothes")
over_ten = greater_than(10)
```

Первая строка дополнительно фиксирует категорию одежды; `filter_clothes`
теперь принимает только список. Вторая строка создаёт предикат с порогом `10`.

```python
print("Электроника:", filter_by("category")("electronics")(items))
print("Одежда:", filter_clothes(items))
print("Больше 10:", list(filter(over_ten, numbers)))
print("Больше 5:", list(filter(greater_than(5), numbers)))
```

Каждый `print` выводит подпись и результат. Первые две строки демонстрируют
фильтрацию словарей, последние две — фильтрацию чисел с разными порогами.
В последней строке предикат создаётся прямо в аргументах `filter`.

## 6. Уровень 4: рефлексия

Каррирование позволило задавать параметры по шагам и создавать специализированные
функции. Например, можно один раз подготовить фильтр электроники и применять
его к нескольким спискам. `greater_than(10)` превращает общий способ сравнения
в готовый предикат, который подходит для `filter`.

Частичное применение через `partial` также фиксирует аргументы, но не требует
представлять функцию цепочкой одноаргументных функций. Поэтому каррирование
и частичное применение — связанные, но разные приёмы.

Обойтись без каррирования можно:

```python
def filter_by_plain(key, value, items):
    return [item for item in items if item[key] == value]


filter_by_category_plain = partial(filter_by_plain, "category")
```

Для разового отбора можно написать списковое включение непосредственно.
Каррирование полезно здесь как способ настройки и повторного использования
функций, но не является обязательным условием решения задачи.

## 7. Чистота и граничные случаи

Фильтры не изменяют входной список или словари и не печатают результаты.
Они создают новый внешний список и сохраняют порядок элементов.
При одинаковых обычных входных данных результаты одинаковы.
Вывод через `print` находится отдельно и является побочным эффектом демонстрации.

Словари в результирующем списке — те же объекты, что во входном: глубокого
копирования здесь нет. Сами функции их не изменяют, но последующее изменение
словаря через результат будет видно и через исходный список.

Для пустого входа и отсутствия совпадений получается `[]`.
Отсутствующий ключ приводит к `KeyError`, как при обычном `item[key]`.
Числа, равные порогу, не включаются в результат.
