# Лабораторная работа № 2. Анализ текста чистыми функциями

В файле `word_analysis.py` находятся три функции: разбиение текста на слова,
подсчёт частот и выбор самого частого слова. В конце файла показано их применение
к заданному отрывку текста. Код использует только стандартную библиотеку Python.

## Запуск

Из корневой папки проекта:

```powershell
python Лаба_2/word_analysis.py
```

Требуется Python 3.9 или новее: в коде используются аннотации `list[str]`
и `dict[str, int]`.

## 1. Импорты

```python
import re
from collections import Counter
from typing import Optional
```

- `import re` подключает модуль регулярных выражений. С его помощью программа
  находит слова по заданному шаблону.
- `from collections import Counter` импортирует класс `Counter` для подсчёта
  повторений. Благодаря прямому импорту можно писать `Counter(words)` без
  префикса `collections.`.
- `from typing import Optional` импортирует обозначение типа, допускающего
  отсутствие результата: `Optional[str]` означает «строка или `None`».

## 2. Разбиение текста: split_words

```python
def split_words(text: str) -> list[str]:
    return re.findall(r"[a-zA-Zа-яА-ЯёЁ0-9]+", text.lower())
```

Первая строка объявляет функцию:

- `def` начинает определение функции;
- `split_words` — её имя;
- `text` — параметр, через который поступает исходный текст;
- `: str` указывает ожидаемый тип аргумента — строку;
- `-> list[str]` указывает тип результата — список строк;
- двоеточие и отступ обозначают начало и границы тела функции.

Аннотации объясняют назначение данных, но сами по себе не проверяют их типы
при выполнении программы.

Во второй строке сначала выполняется `text.lower()`: создаётся строка в нижнем
регистре. Например, `"Я достаю"` становится `"я достаю"`. Это позволяет считать
`"Я"` и `"я"` одним словом. Исходная строка не изменяется.

Затем `re.findall` ищет все неперекрывающиеся совпадения с шаблоном и возвращает
их в новом списке. Шаблон `r"[a-zA-Zа-яА-ЯёЁ0-9]+"` устроен так:

| Часть | Значение |
| --- | --- |
| `r"..."` | Сырая строка; обратные косые черты, если они появятся, передаются буквально. В этом шаблоне их нет, поэтому префикс `r` не меняет результат. |
| `[...]` | Один символ из перечисленных диапазонов и отдельных символов. |
| `a-z` и `A-Z` | Строчные и прописные латинские буквы без диакритики. |
| `а-я` и `А-Я` | Строчные и прописные русские буквы, кроме `ё` и `Ё`. |
| `ёЁ` | Буквы `ё` и `Ё`, добавленные отдельно, поскольку они не входят в диапазоны выше. |
| `0-9` | Цифры от 0 до 9. |
| `+` | Один или больше подходящих символов подряд. |

После `lower()` прописные диапазоны фактически не нужны для обычных русских
и английских букв, но оставлены в точности по примеру задания.

Пробелы, запятые, точки, дефисы и подчёркивания не входят в шаблон: они разделяют
совпадения и в список не попадают. Например:

```python
split_words("Привет, МИР! Ёж 123 имя_поля")
# ['привет', 'мир', 'ёж', '123', 'имя', 'поля']
```

Таким образом, последовательность цифр тоже считается словом по правилам этой
работы. Шаблон рассчитан на указанные русские и латинские буквы; он не является
универсальным разбором слов всех языков. `return` возвращает полученный список
и завершает выполнение функции.

## 3. Подсчёт частот: count_word_frequencies

```python
def count_word_frequencies(words: list[str]) -> dict[str, int]:
    return dict(Counter(words))
```

В первой строке `words: list[str]` обозначает входной список слов.
`dict[str, int]` обозначает возвращаемый словарь: ключом будет слово,
а значением — целое число его вхождений.

Выражение во второй строке вычисляется изнутри наружу:

1. `Counter(words)` проходит по списку и создаёт новый счётчик повторений.
2. `dict(...)` преобразует счётчик в обычный словарь, как требуется в задании.
3. `return` возвращает этот словарь.

```python
count_word_frequencies(["я", "достаю", "я"])
# {'я': 2, 'достаю': 1}
```

Функция не меняет исходный список, не сортирует его и не удаляет элементы.
Она также не приводит слова к нижнему регистру: это уже делает `split_words`.
При отдельном вызове слова `"Мир"` и `"мир"` будут разными ключами.

## 4. Выбор самого частого слова: top_word

```python
def top_word(freq: dict[str, int]) -> Optional[str]:
    return max(freq, key=freq.get) if freq else None
```

Первая строка задаёт входной словарь частот `freq`. Результат `Optional[str]` —
слово в виде строки либо `None`, если словарь пуст.

Вторая строка содержит условное выражение `результат if условие else другой_результат`:

1. Сначала проверяется `freq`. Непустой словарь считается истинным, пустой — ложным.
2. Если словарь непустой, выполняется `max(freq, key=freq.get)`.
3. Перебор `freq` даёт ключи словаря, то есть слова.
4. `key=freq.get` передаёт метод, который для каждого слова возвращает его частоту.
   Например, для `{"в": 4, "на": 4, "под": 2}` вызов `freq.get("под")` даст `2`.
   Здесь метод передаётся без скобок: вызывать его для каждого ключа будет `max`.
5. `max` сравнивает частоты, но возвращает соответствующий ключ — само слово,
   а не количество его вхождений.
6. Если словарь пуст, возвращается `None`. В этом случае `max` не вызывается,
   поэтому ошибки поиска максимума в пустой последовательности не возникает.

При равных частотах возвращается первый встретившийся ключ. Словарь сохраняет
порядок добавления ключей, поэтому в цепочке наших функций побеждает слово,
которое раньше встретилось в тексте среди слов с максимальной частотой.

## 5. Демонстрационный блок

```python
if __name__ == "__main__":
```

При прямом запуске файла Python присваивает его переменной `__name__` значение
`"__main__"`. Условие становится истинным, и выполняются инструкции с отступом
под ним. При импорте файла как модуля этот блок не выполняется: функции можно
использовать без автоматического вывода примера.

```python
    TEXT = (
        "Я достаю из широких штанин дубликатом бесценного груза. "
        "Читайте, завидуйте, я — гражданин Советского Союза."
    )
```

Здесь записан заключительный отрывок из стихотворения Владимира Маяковского
[«Стихи о советском паспорте»](https://ru.wikisource.org/wiki/Стихи_о_советском_паспорте_(Маяковский)).
`TEXT` хранит исходную строку. Прописное
имя показывает, что значение предполагается использовать как константу, хотя
Python технически не запрещает присвоить ему другое значение.

Круглые скобки позволяют переносить длинную запись на несколько строк.
Соседние строковые литералы автоматически соединяются в одну строку. Это
не список и не кортеж: запятых между строками нет. Пробелы в конце фрагментов
нужны, чтобы слова на границах строк не склеились.

```python
    print("1) split_words:")
    print(split_words(TEXT))
    print()
```

Первая инструкция печатает подпись. Вторая сначала вызывает `split_words(TEXT)`,
затем выводит полученный список. `print()` без аргументов добавляет пустую строку
для удобства чтения. Результат начинается с `['я', 'достаю', 'из', 'широких', ...]`.

```python
    print("2) count_word_frequencies:")
    print(count_word_frequencies(split_words(TEXT)))
    print()
```

После подписи выполняются вложенные вызовы: сначала `split_words(TEXT)` получает
список, затем `count_word_frequencies(...)` считает слова и передаёт словарь
в `print`. В отрывке слово `"я"` встречается дважды, остальные слова — по одному разу.

```python
    print("3) top_word:")
    print(top_word(count_word_frequencies(split_words(TEXT))))
    print()
```

Вложенные вызовы образуют полную цепочку:

```text
TEXT → split_words → список → count_word_frequencies → словарь → top_word → слово
```

Для данного отрывка выводится `я`: это слово имеет максимальную частоту `2`.
Повторные вызовы предыдущих функций
оставлены по примеру задания: каждый блок явно показывает нужные ему вычисления.

```python
    print("4) пустая строка:")
    print(top_word({}))
```

Несмотря на подпись «пустая строка», непосредственно здесь проверяется пустой
словарь `{}`. Функция возвращает `None`, и `print` выводит его в консоль.
Для пустой исходной строки полная цепочка тоже даст `None`:

```python
split_words("")                                  # []
count_word_frequencies([])                        # {}
top_word({})                                     # None
top_word(count_word_frequencies(split_words(""))) # None
```

## 6. Чистота и детерминированность

Все три функции чистые в принятом для этой задачи смысле: получают данные
через аргументы, возвращают результат, не изменяют входные объекты и не создают
наблюдаемых побочных эффектов. Они не выводят текст, не читают файлы и не используют
время или случайные числа. Создание и заполнение нового объекта `Counter`
внутри вычисления не меняет исходный список или внешнее состояние.

Функции детерминированы: при одинаковых входных данных возвращают одинаковые
результаты по содержимому. Для ничьей в `top_word` учитывается также порядок
ключей: словари с одинаковыми парами, но разным порядком вставки могут дать
разных победителей при равных частотах.

Побочный эффект есть у демонстрационного блока: `print` выводит данные
в консоль. Это не нарушает чистоту трёх функций, поскольку вывод находится
за их пределами.

Пустая строка, строка из пробелов или одних знаков препинания превращается
в пустой список, затем в пустой словарь, а итоговым результатом становится `None`.
