# Лабораторная работа 1. Анализ продаж

## Исходные данные

Отдельный CSV-файл не используется. Таблица хранится в программе в строковой
константе `SALES_DATA`:

```csv
date,item,quantity,price
2026-09-01,Кофе,2,250
2026-09-02,Чай,3,150
2026-09-03,Торт,1,1200
```

Константы `QUANTITY_FIELD` и `PRICE_FIELD` содержат названия расчётных
столбцов.

## Выполнение задачи

### Уровень 1

Функция `parse_csv(data)` получает CSV в виде строки. `StringIO` представляет
строку как файл в памяти, а `csv.DictReader` преобразует каждую запись в
словарь. Заголовки `date`, `item`, `quantity`, `price` становятся ключами.

### Уровень 2

Функция `compute_revenue(rows)` для каждой строки вычисляет:

```text
int(quantity) * float(price)
```

Функция `sum` складывает результаты. Для пустого списка результат равен `0`.

### Уровень 3

Функция `top_item(rows)` использует `max` и сравнивает строки по значению
`quantity * price`. Аргумент `default=None` означает, что для пустого списка
функция возвращает `None`.

## Проверка чистоты

Три функции не читают файлы, ничего не выводят и не изменяют аргументы.
При одинаковых допустимых аргументах они возвращают одинаковый результат.
Следовательно, на своих областях определения они являются чистыми.

Основная программа передаёт константу `SALES_DATA` функции `parse_csv` и
выводит результаты через `print`. Вывод имеет побочный эффект, но выполняется
за пределами трёх чистых функций.

Пустая исходная строка превращается в пустой список. Если пустым окажется
значение `quantity` или `price`, преобразование числа завершится исключением.
Такие значения не входят в область определения вычислительных функций.

## Множества значений

- `parse_csv`: принимает корректную строку CSV и возвращает `list[dict]`;
- `compute_revenue`: принимает список словарей с целым `quantity` и
  вещественным `price`, записанными строками, и возвращает число;
- `top_item`: принимает такой же список и возвращает один словарь либо
  `None`.
